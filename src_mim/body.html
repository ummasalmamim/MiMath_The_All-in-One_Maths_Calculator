    Complex numbers use i, for example (3+4i)*(1-2i). Binary and hex work too: 0b1010 + 0xFF. See the Tools tab for every function.

    Tips for typing
    • Implicit multiplication works: 2(3+4), 3pi, 2sin(30).
    • log(x) is base 10, ln(x) is natural, logb(x, 5) is any base.
    • Ans is your last result. 5!, nCr(5,2), nPr(5,2), 7 mod 3 and 20% all work.
    • The DEG / RAD switch only affects this Calculator tab. Solve, Graph and Charts use radians.
